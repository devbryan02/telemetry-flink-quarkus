# Planes de implementación

Los planes se organizan por iniciativa. Cada carpeta reúne sus incrementos y un README con el orden, las dependencias y el enlace a la especificación correspondiente.

## Iniciativas

## Convención

- Una carpeta por iniciativa, con nombre en minúsculas y palabras separadas por guiones.
- Dentro de cada carpeta, conservar la numeración de los incrementos y sus nombres descriptivos: `01-<descripcion>.md`.
- El README de cada iniciativa documenta su especificación, el orden de ejecución y las dependencias entre planes.
- Agregar al índice general una iniciativa cuando tenga planes redactados.

Los futuros planes de [persistencia de posiciones y viajes](../specs/persistencia-posiciones-viajes.md) se ubicarán en `persistencia-posiciones-viajes/` cuando se redacten.

Los planes existentes de `docs/superpowers/plans/` conservan su ubicación y no forman parte de esta reorganización.
